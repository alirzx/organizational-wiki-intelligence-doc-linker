# Configuration reference

All application settings use the `DOC_LINKER_` prefix. `.env.example` is the canonical template.

## Compose-only
`COMPOSE_PROFILES`, `DOC_LINKER_IMAGE`, `TORCH_INDEX_URL`, `DOC_LINKER_REDIS_IMAGE`, `DOC_LINKER_QDRANT_IMAGE`.

## API/auth
`DOC_LINKER_API_HOST`, `DOC_LINKER_API_PORT`, `DOC_LINKER_API_AUTH_TOKEN`, `DOC_LINKER_LOG_LEVEL`.

## MinIO
`DOC_LINKER_MINIO_ENDPOINT`, `DOC_LINKER_MINIO_ACCESS_KEY`, `DOC_LINKER_MINIO_SECRET_KEY`, `DOC_LINKER_MINIO_SECURE`, `DOC_LINKER_MINIO_BUCKET`, `DOC_LINKER_DOCUMENT_PREFIX`, `DOC_LINKER_LINKING_DIR`, `DOC_LINKER_MINIO_AUTO_CREATE_BUCKET`, `DOC_LINKER_MAX_ARTIFACT_BYTES`, `DOC_LINKER_WRITE_AUDIT_ARTIFACTS`.

## Redis/Celery
`DOC_LINKER_REDIS_URL`, `DOC_LINKER_CELERY_BROKER_URL`, `DOC_LINKER_CELERY_RESULT_BACKEND`, `DOC_LINKER_CELERY_QUEUE`, `DOC_LINKER_JOB_TTL_SECONDS`, `DOC_LINKER_LOCK_TTL_SECONDS`, `DOC_LINKER_TASK_MAX_RETRIES`, `DOC_LINKER_TASK_RETRY_BACKOFF_SECONDS`.

## Qdrant
`DOC_LINKER_QDRANT_URL`, `DOC_LINKER_QDRANT_API_KEY`, `DOC_LINKER_QDRANT_COLLECTION`, `DOC_LINKER_QDRANT_DENSE_VECTOR_NAME`, `DOC_LINKER_QDRANT_SPARSE_VECTOR_NAME`, `DOC_LINKER_QDRANT_VECTOR_SIZE`, `DOC_LINKER_QDRANT_TIMEOUT_SECONDS`, `DOC_LINKER_QDRANT_UPSERT_BATCH_SIZE`.

## Models
API/worker should use HTTP while the private model-service uses BGE. Variables: `DOC_LINKER_EMBEDDING_BACKEND`, `DOC_LINKER_EMBEDDING_MODEL`, `DOC_LINKER_EMBEDDING_DEVICE`, `DOC_LINKER_EMBEDDING_USE_FP16`, `DOC_LINKER_EMBEDDING_BATCH_SIZE`, `DOC_LINKER_EMBEDDING_MAX_LENGTH`, `DOC_LINKER_ENABLE_SPARSE`, `DOC_LINKER_RERANKER_BACKEND`, `DOC_LINKER_RERANKER_MODEL`, `DOC_LINKER_RERANKER_DEVICE`, `DOC_LINKER_RERANKER_USE_FP16`, `DOC_LINKER_RERANKER_MAX_LENGTH`, `DOC_LINKER_MODEL_SERVICE_URL`, `DOC_LINKER_MODEL_SERVICE_TOKEN`, `DOC_LINKER_MODEL_SERVICE_TIMEOUT_SECONDS`, `DOC_LINKER_MODEL_SERVICE_WARMUP`.

## Chunking
`DOC_LINKER_CHUNK_TARGET_TOKENS`, `DOC_LINKER_CHUNK_MAX_TOKENS`, `DOC_LINKER_CHUNK_MIN_TOKENS`, `DOC_LINKER_CHUNK_OVERLAP_TOKENS`, `DOC_LINKER_SEMANTIC_BREAK_PERCENTILE`.

## Retrieval
`DOC_LINKER_RETRIEVAL_MODE`, `DOC_LINKER_RETRIEVAL_CANDIDATE_LIMIT`, `DOC_LINKER_SEARCH_DEFAULT_LIMIT`, `DOC_LINKER_SEARCH_MAX_LIMIT`, `DOC_LINKER_RRF_K`.

## Callback/identity
`DOC_LINKER_CALLBACK_URL`, `DOC_LINKER_CALLBACK_TOKEN`, `DOC_LINKER_CALLBACK_TIMEOUT_SECONDS`, `DOC_LINKER_CALLBACK_MAX_ATTEMPTS`, `DOC_LINKER_PIPELINE_VERSION`, `DOC_LINKER_CHUNKER_VERSION`.
